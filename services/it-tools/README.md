# IT-Tools

Collection of developer utilities — hash generators, encoders/decoders, formatters, converters, network tools, and more.

> ⏸ **On-demand** (since 2026-09-26) — stopped by default to save RAM.
> `ondemand start it-tools` (alias for `scripts/utils/ondemand.sh`) prints the
> URL; `ondemand stop it-tools` when done.

## Setup

```bash
cd ~/services/it-tools
docker compose up -d
# Open: http://localhost:8085
```

## Port

| Port | Purpose |
|------|---------|
| 8085 | Web UI |
