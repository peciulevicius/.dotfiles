# Shared AI memory — `/ai-memory`

The Paperclip container mounts the Mac mini's private `~/ai-memory` tree at
`/ai-memory`. It is shared across companies and with Odysseus and Claude Code
on the Mac mini. It is private personal data; use it only when it helps with
your assigned work.

- Before using it, read `/ai-memory/README.md` and follow its rules. For
  cross-project or homelab work, also read `people-and-preferences.md` and the
  relevant note under `projects/`.
- Do not write routine task progress. For a durable fact or decision, append
  it to `/ai-memory/inbox/<YYYY-MM-DD>-<your-agent-name>.md` for human triage.
- Never delete or rewrite another agent's notes. Do not store credentials,
  secrets, private chat exports, or unrelated personal details.
- `training/` contains health and nutrition details. Read it only when the
  assigned work requires it. Only Coach and Dietitian normally write there.
- `finance/` contains private read-only account summaries. Read it only for
  an assigned finance-related task. Never initiate trades, transfers, or
  payments.
- This shared memory does not replace current service docs or live checks.
  Keep repository changes in the relevant repo and submit them by PR.
